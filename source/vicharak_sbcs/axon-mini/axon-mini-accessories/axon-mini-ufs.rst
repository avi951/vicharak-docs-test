################################
Axon Mini UFS 3.1 Storage Module
################################

.. warning::
   This accessory/storage option is coming soon.

.. note::

   This HAT is also compatible with Vicharak's Axon Lite.

.. note::

   Connect the UFS storage module while Axon Mini is powered off to avoid any damage.

The Axon Mini UFS 3.1 Storage Module is a modular accessory that attaches to the
board through dedicated board-to-board connectors.

Specifications:
----------------

- UFS 3.1 storage module
- Connects via 2× 30-pin B2B connectors (signal + power)
- High-speed boot and root filesystem storage option for Axon Mini

`Using guide in Linux </vicharak_sbcs/axon-mini/storage/ufs.html>`_

`Available on Vicharak Store <https://store.vicharak.in/?product_cat=accessories>`_
